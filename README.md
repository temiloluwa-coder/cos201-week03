Three beginner Java programs that read input from the keyboard.

## Programs

1. **SimpleCalculator.java** - takes two numbers and an operator (+, -, *, /) and prints the result. Handles division by zero and invalid operators.
2. **AverageCalculator.java** - asks how many numbers you want, reads them, then prints the sum and average.
3. **ItemCost.java** - takes an item name, price and quantity, then prints the total cost.

## Requirements

- Java Development Kit (JDK) 8 or newer
- Check with: `java -version` and `javac -version`

## How to compile and run

Open a terminal in this folder, then for each program:

```
javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
```

## Sample run (SimpleCalculator)

```
Enter first number: 12
Enter an operator (+, -, *, /): *
Enter second number: 3
```
